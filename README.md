# Portal Rush Brasil - Landing Page

Esta é a landing page principal do Portal Rush Brasil, focada na relação entre a banda Rush, o esporte e o fã Felipe Andreoli.

## Arquivos Principais

- **index.html**: A Landing Page oficial ("O Som do Esporte"). Este arquivo foi anteriormente nomeado como `suzuki-rush-style.html`.
- **playlist-reference.html**: Versão de referência do site original (Playlist do Rush).
- **design-system.html**: Documentação do sistema de design, cores, tipografia e componentes utilizados.

## Execução Local

Para visualizar o projeto corretamente com todos os assets, recomenda-se usar um servidor HTTP:

```bash
npx serve . -l 3001
```

## Estética e Design
O projeto utiliza uma estética premium com:
- Tema escuro (`#0a0e1a`) com acentos em verde Spotify (`#1db954`).
- Cursor personalizado dinâmico.
- Animações de entrada (*reveal*) e letreiros digitais (*tickers*).
- Galeria de vinis 3D interativa.
